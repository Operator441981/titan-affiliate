Swan Performance 1

Trend Reader: an independent project operated by Justin Swan, Baton Rouge, Louisiana, USA

Swan Performance 1 Trend Reader is a small project that reads public trend data from Pinterest's Trends API to help decide which technology topics are worth creating Pins about. Pins link to products through the Amazon Associates program.

The project accesses only the trend data of the Pinterest account that owns it. It does not collect, store, or sell data about other Pinterest users.
